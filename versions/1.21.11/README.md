# RuleHelper 2.0.0 Donator — Minecraft 1.21.11

Донатерская версия: редактор общих и индивидуальных причин, компактное меню правил, проверка банов/мутов/варнов/киков, дневная история и настраиваемые префиксы.

Нужны Java 21 и Fabric Loader 0.19.3+. Установите один `RuleHelper-1.21.11-Fabric.jar` из [единого релиза](https://github.com/DimonGonBon/rulehelper-minecraft-hypemc/releases/tag/v2.0.0) вместо старого мода.

[Полная инструкция и изменения](../../RELEASE_NOTES.md).

Сборка: `./gradlew clean build`.
