# RuleHelper для Minecraft 1.21.11

Клиентский Fabric-мод. Исходники восстановлены из переданных JAR-файлов и затем обновлены; поэтому они могут отличаться от исходного проекта автора мода.

## Возможности

- Выбор ника игрока в чате с привязкой к нажатому сообщению.
- Список правил и быстрые команды наказаний.
- Команды размута и разбана с вариантом `-g`.
- Сохранение собственного ника и выбранного уровня доната: `Правитель+` или `Staff-`.
- Доступная функция `/pex user <цель>`: отправляются `op <сохранённый ник>`, затем `pex user <цель>`; возможность зависит от серверных прав.
- Предупреждение о правиле 3.4 при выборе донатной группы.

## Сборка

Нужен JDK 21. Выполните `./gradlew --no-daemon clean build`. JAR появится в `build/libs/` под именем `RuleHelper-1.21.11-Fabric-1.1.0.jar` (в релизе файл называется `RuleHelper-1.21.11-Fabric.jar`).
