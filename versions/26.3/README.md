# RuleHelper — Fabric для Minecraft 26.3

Донатерская версия RuleHelper для Minecraft Java Edition 26.3.

## Установка

1. Установить Minecraft Java Edition 26.3 с Fabric Loader 0.20.1 или новее и Java 25.
2. Удалить старый RuleHelper из папки `mods` этого профиля.
3. Положить туда `RuleHelper-26.3-Fabric.jar`.

Fabric API не требуется. Ник и выбранная группа доната хранятся локально в `config/rulehelper.properties`; мод не проверяет донат на сервере.

## Функции

- Меню по нажатию на ник в чате с поиском по правилам и отдельной панелью выбранного правила.
- В меню доступны 26 правил; пункты 1.3 и 4.1 исключены из донатерской сборки.
- Выбор ника из чата остаётся с прежним ограничением: латинские буквы, цифры и подчёркивание. Русские буквы разрешаются только в полях запроса доказательств модерской версии.
- Выбор группы «Правитель+» / «Staff-» сохраняет прежнюю логику команд: правила 1–3 используют `-g` для группы Правитель+, правила 4–5 выполняются локально без `-g`.
- Быстрые действия: копирование ника, `/hist`, `/shist`, `/dupeip`, разбан и размут.
- Пункты `/hist` и «Разбан / размут» поменяны местами.
- В этой донатерской версии нет `/pex user` и запроса доказательств.
- Дневная история открывается клавишей F9 и получает список через `/shist <ваш ник>`; каждое наказание попадает в счётчик только если его относительное время относится к сегодняшней дате.

## История за день · 1.3.5

Исправлен подсчёт «наказаний за день»: мод анализирует время у каждой записи `/shist`, поэтому наказания со вчерашней датой не увеличивают сегодняшние счётчики. Если список не обновился, нажмите «Обновить» в окне истории. Ответ на внутренний запрос для собственного ника скрыт из общего чата, но учитывается в окне. Ручной `/shist <чужой ник>` выводится в чат как обычно.

## Сборка

JDK 25: `./gradlew build` (Windows: `gradlew.bat build`).

JAR в `artifacts/RuleHelper-26.3-Fabric.jar` проходит регрессионные проверки до публикации.
