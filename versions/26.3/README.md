# RuleHelper — Fabric для Minecraft 26.3

Проверенный в игре перенос полного функционала RuleHelper 1.2.1 на Minecraft Java Edition 26.3.

## Установка

1. Установить Minecraft Java Edition 26.3 с Fabric Loader 0.20.1 или новее и Java 25.
2. Удалить старый RuleHelper из папки `mods` этого профиля.
3. Положить туда `RuleHelper-26.3-Fabric.jar`.

Fabric API не требуется. Сохранённые ник и группа читаются из прежнего `config/rulehelper.properties`.

## Функции

- Меню по нажатию на ник, правила и варианты наказаний.
- Группы «Правитель+» / «Staff-» и прежняя логика `-g`.
- Разбан / размут, `/hist`, `/shist`, `/dupeip`.
- Последовательные `/op <сохранённый ник>` и `/pex user <выбранный ник>`.
- Экран проверки объявлений о банах и мутах с коррекцией по 3.4.
- В 26.3 наказание берётся из исходного сообщения выбранной строки; соседние сообщения не объединяются.
- Кнопка «Копировать ник» копирует ник выбранного игрока в буфер обмена и закрывает меню.
- Учтены новый ввод SDL, новый интерфейс отрисовки и внутренние имена Minecraft.

## Сборка

JDK 25: `./gradlew build` (Windows: `gradlew.bat build`).

Альтернативная сборка без Gradle: `python3 tools/build-standalone.py` при установленном JDK 25 и `JAVA_HOME`.
Она скачивает официальные зависимости, компилирует мод с проверкой Mixin, запускает регрессионную проверку координат и разбора наказаний, затем создаёт JAR. Minecraft и зависимости внутрь JAR не включаются.

Публичная сборка v1.3.1 содержит функцию копирования ника. Внутренняя версия JAR указана в `fabric.mod.json`.
