# RuleHelper для Minecraft 1.21.4

Клиентский Fabric-мод, портированный на Minecraft 1.21.4.

Возможности: выбор ника в чате, список правил, команды наказаний и размута/разбана с `-g`, сохранение собственного ника и уровня доната (`Правитель+` или `Staff-`), а также `/pex user <цель>` с последовательностью `op <сохранённый ник>` → `pex user <цель>`. Сервер сам проверяет права на команды.

Исходники восстановлены и портированы из доступных JAR-файлов; они могут отличаться от первоначального исходного проекта.

## Сборка

Нужен JDK 21. Выполните `./gradlew --no-daemon clean build`. JAR появится в `build/libs/` под именем `RuleHelper-1.21.4-Fabric-1.1.0.jar` (в релизе файл называется `RuleHelper-1.21.4-Fabric.jar`).
