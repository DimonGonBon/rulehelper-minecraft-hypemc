# RuleHelper Donator для Minecraft 1.21.4

Версия 1.3.6 — перенос актуальной донатерской версии 26.3: синий компактный интерфейс, правила и действия, стили причин, префиксы чата и наказаний, копирование ников, звуковые уведомления, дневная история и автоматическое определение режима снятия наказания.

Установка: Fabric Loader 0.19.3 или новее, Java 21. Удалите старый RuleHelper и поместите один JAR для своей версии Minecraft в папку mods.

Нажмите префикс перед ником в чате, чтобы открыть меню; сам ник копируется нажатием. Home открывает настройки; F9 по умолчанию открывает историю за календарный день. В настройках укажите свой серверный ник. Для истории мод запрашивает /shist собственного ника и скрывает ответ; история другого игрока остаётся в чате.

Функции запроса доказательств и другие инструменты модераторов отсутствуют в донатерской сборке. Все права на команды проверяются сервером.

Сборка: ./gradlew clean build (JDK 21).
