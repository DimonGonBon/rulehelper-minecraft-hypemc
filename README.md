# RuleHelper для Minecraft

Клиентский Fabric-мод для Minecraft Java Edition. Доступны сборки для **26.3**, **1.21.11** и **1.21.4**.

## Скачать

Откройте [последний релиз](https://github.com/DimonGonBon/rulehelper-minecraft-hypemc/releases/latest) и скачайте **один** файл, подходящий к версии игры:

| Версия Minecraft | Файл |
| --- | --- |
| 26.3 | `RuleHelper-26.3-Fabric.jar` |
| 1.21.11 | `RuleHelper-1.21.11-Fabric.jar` |
| 1.21.4 | `RuleHelper-1.21.4-Fabric.jar` |

Сборка 26.3 доступна в [релизе v1.3.1-26.3](https://github.com/DimonGonBon/rulehelper-minecraft-hypemc/releases/tag/v1.3.1-26.3). Сборки 1.21.11 и 1.21.4 — в [релизе v1.2.1](https://github.com/DimonGonBon/rulehelper-minecraft-hypemc/releases/tag/v1.2.1).

Не кладите несколько файлов в одну папку `mods`: выберите только сборку для своей версии Minecraft.

## Установка

1. Убедитесь, что у вас **Minecraft Java Edition** нужной версии.
2. Установите **Fabric Loader** для этой же версии игры с помощью [официального установщика Fabric](https://fabricmc.net/use/installer/). Для **26.3** нужны **Java 25** и **Fabric Loader 0.20.1+**; для **1.21.11 / 1.21.4** — Java 21. Fabric API не требуется.
3. Скачайте подходящий JAR из раздела [Releases](https://github.com/DimonGonBon/rulehelper-minecraft-hypemc/releases/latest).
4. Переместите JAR в папку `mods` выбранной игровой установки. Если папки нет, создайте её:
   - **Windows:** `%appdata%\\.minecraft\\mods`
   - **macOS:** `~/Library/Application Support/minecraft/mods`
   - **Linux:** `~/.minecraft/minecraft/mods`
   - В стороннем лаунчере используйте папку `mods` именно этого игрового профиля.
5. В лаунчере выберите профиль **Fabric Loader** с той же версией Minecraft и запустите игру.

## Использование

1. Подключитесь к серверу и откройте чат.
2. Нажмите **левой кнопкой мыши прямо по нику игрока** в сообщении чата. Откроется меню RuleHelper для выбранного ника. Кликабельные элементы чата с собственным действием, например `[Add]`, сохраняют своё обычное поведение и не открывают меню RuleHelper.
3. При первом запуске укажите **свой ник на сервере** и выберите группу:
   - **Правитель+** — для соответствующей группы и выше; команды правил 1–3 отправляются с `-g`, а правила 4 — без `-g`.
   - **Staff-** — для соответствующей группы и ниже; команды отправляются без `-g`.
   
   Выбирайте только группу, которая у вас действительно есть. Выбор неверной группы может считаться нарушением правила 3.4 и привести к последствиям на сервере. Эти настройки сохраняются в локальном файле `config/rulehelper.properties`; мод сам не проверяет ваш донат.
4. В меню выберите категорию правил, затем нужное правило и действие, если для него есть варианты. Мод отправит соответствующую команду в чат сервера.
5. Кнопка **«Разбан / размут»** открывает варианты разбана и размута. Команды используют выбранную группу и формат, заданный модом.
6. Кнопка **«Копировать ник»** копирует в буфер обмена ник из заголовка меню и закрывает меню.
7. Кнопка **«/pex user»** отправляет две команды по очереди: сначала `/op <ваш сохранённый ник>`, затем `/pex user <выбранный ник>`. Сервер сам проверяет права и может отклонить команды; мод не выдаёт права в обход проверок сервера.
8. Чтобы изменить сохранённый ник или группу, нажмите **«Изменить»** в меню.

Мод работает на стороне клиента и отправляет команды подключённому серверу. Доступность и результат команд определяются настройками и правами на сервере.

## Перенос на Minecraft 26.3

- v1.3.1: добавлена кнопка **«Копировать ник»** в меню выбранного игрока. Она помещает ник в буфер обмена и закрывает меню.

- Перенесён полный функционал мода: меню, команды, настройки и экран проверки наказаний.
- Адаптированы ввод SDL, новый интерфейс отрисовки и структура чата. Наказание определяется по исходному сообщению нажатой строки.
- Опубликована проверенная в игре первая сборка 26.3. JAR переименован без изменения содержимого; внутренняя версия — `1.3.0-test.1`.
- Сохранённые настройки используются из прежнего `config/rulehelper.properties`. Перед установкой удалите старый JAR RuleHelper из `mods`.

## Изменения в v1.2.1

- Исправлен выбор наказания при нажатии по сообщению в чате: если рядом есть другие строки чата, мод больше не подменяет выбранное наказание соседним сообщением. Перенесённое на несколько строк объявление собирается только из строк этого же сообщения.
- Обновлены сборки для Minecraft 1.21.11 и 1.21.4.

## Для разработчиков

| Версия Minecraft | Исходники | Собранный JAR в репозитории |
| --- | --- | --- |
| 26.3 | `versions/26.3` | `artifacts/RuleHelper-26.3-Fabric.jar` |
| 1.21.11 | `versions/1.21.11` | `artifacts/RuleHelper-1.21.11-Fabric.jar` |
| 1.21.4 | `versions/1.21.4` | `artifacts/RuleHelper-1.21.4-Fabric.jar` |

Версии 1.21.11 и 1.21.4 собираются с JDK 21 через Gradle wrapper; 26.3 — с JDK 25. Для 26.3 также доступен `versions/26.3/tools/build-standalone.py`. GitHub Actions собирает обе версии после push или pull request и прикладывает JAR как workflow artifacts.

Исходники восстановлены из доступных JAR-файлов и адаптированы для указанных версий Minecraft, поэтому могут отличаться от исходного проекта автора.
