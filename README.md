## Главное в 2.0

- **Свой стиль причин:** общий шаблон, индивидуальный шаблон для каждого доступного пункта, отдельное оформление снятия. Цвета, начертание, символы, предпросмотр и сохранение настроек.
- **Проверка банов, мутов, варнов и киков:** корректные команды снятия, учёт режима из объявления и отдельное подтверждение 3.4.
- **Цветной курсив:** белый пункт, голубой текст наказания, зелёный текст снятия.
- **Единый компактный синий интерфейс** на всех трёх версиях Minecraft.
- Копирование ников, кликабельные префиксы, звуковые предупреждения и история наказаний за календарный день.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) под нужную версию Minecraft и Java из таблицы выше.
2. Удалите предыдущий JAR RuleHelper из папки `mods` игрового профиля.
3. Поместите туда один JAR из релиза 2.0 и запустите профиль Fabric.

Существующие настройки подхватываются из `config/rulehelper.properties`.

## Как пользоваться

- **Меню игрока:** откройте чат и нажмите префикс RuleHelper перед ником. При первом запуске укажите свой ник на сервере и настоящую группу «Правитель+» / «Staff–».
- **Копирование:** сам ник игрока копируется нажатием. В объявлениях 🛡 копирует ник выдавшего наказание, ☠ — получившего.
- **Наказание:** выберите категорию, правило и действие. Доступность команд зависит от серверных прав.
- **Свои причины:** «Причина» → «Свой стиль». Вкладки «Общий», «По правилам», «Снятие». `{rule}` — пункт, `{reason}` — название причины, `{extra}` — уточнение варианта. Нажмите «Сохранить».
- **Проверка наказания:** нажмите текст объявления о бане, муте, предупреждении или кике. Сверьте данные и подтвердите нужное действие.
- **Настройки:** Home. Здесь меняются префиксы и клавиша дневной истории.
- **Сегодняшние наказания:** F9 по умолчанию. Мод разбирает время записей `/shist <ваш ник>`; внутренний ответ скрывается, обычная история другого игрока видна. Количество записей определяется ответом сервера.

«Правитель+» сохраняет глобальный вариант для разделов правил 1–3; «Staff–» — локальный. Разделы 4–5 и снятие по объявлению используют соответствующий режим. Мод не выдаёт права.

Запрос доказательств, служебные экраны модераторов и очередь нарушителей в донатерские JAR не включены.

## Разработка и проверки

Исходники: `versions/26.3`, `versions/1.21.11`, `versions/1.21.4`. Для сборки выполните `./gradlew clean build` в папке нужной версии с соответствующим JDK.

GitHub Actions собирает все три версии, запускает проверки кликов, истории, шаблонов, коррекции наказаний и групп доната. Перед публикацией проверяются версия/назначение JAR и отсутствие служебных модераторских классов. Сборки из раздела Releases являются актуальными файлами для установки.

Исходники проекта были восстановлены из доступных JAR и затем доработаны.
