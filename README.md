# RuleHelper для Minecraft

Клиентский Fabric-мод для Minecraft Java Edition. Доступны сборки для **1.21.11** и **1.21.4**.

## Скачать

Откройте [последний релиз](https://github.com/DimonGonBon/rulehelper-minecraft-hypemc/releases/latest) и скачайте **один** файл, подходящий к версии игры:

| Версия Minecraft | Файл |
| --- | --- |
| 1.21.11 | `RuleHelper-1.21.11-Fabric.jar` |
| 1.21.4 | `RuleHelper-1.21.4-Fabric.jar` |

Не кладите оба файла в одну папку `mods`: выберите только сборку для своей версии Minecraft.

## Установка

1. Убедитесь, что у вас **Minecraft Java Edition** нужной версии.
2. Установите **Fabric Loader** для этой же версии игры с помощью [официального установщика Fabric](https://fabricmc.net/use/installer/). Для запуска мода требуется Java 21.
3. Скачайте подходящий JAR из раздела [Releases](https://github.com/DimonGonBon/rulehelper-minecraft-hypemc/releases/latest).
4. Переместите JAR в папку `mods` выбранной игровой установки. Если папки нет, создайте её:
   - **Windows:** `%appdata%\\.minecraft\\mods`
   - **macOS:** `~/Library/Application Support/minecraft/mods`
   - **Linux:** `~/.minecraft/mods`
   - В стороннем лаунчере используйте папку `mods` именно этого игрового профиля.
5. В лаунчере выберите профиль **Fabric Loader** с той же версией Minecraft и запустите игру.

## Использование

1. Подключитесь к серверу и откройте чат.
2. Нажмите **левой кнопкой мыши прямо по нику игрока** в сообщении чата. Откроется меню RuleHelper для выбранного ника.
3. При первом запуске укажите **свой ник на сервере** и выберите группу:
   - **Правитель+** — для соответствующей группы и выше; команды правил 1–3 отправляются с `-g`, а правила 4 — без `-g`.
   - **Staff-** — для соответствующей группы и ниже; команды отправляются без `-g`.
   
   Выбирайте только группу, которая у вас действительно есть. Выбор неверной группы может считаться нарушением правила 3.4 и привести к последствиям на сервере. Эти настройки сохраняются в локальном файле `config/rulehelper.properties`; мод сам не проверяет ваш донат.
4. В меню выберите категорию правил, затем нужное правило и действие, если для него есть варианты. Мод отправит соответствующую команду в чат сервера.
5. Кнопка **«Разбан / размут»** открывает варианты разбана и размута. Команды используют выбранную группу и формат, заданный модом.
6. Кнопка **«/pex user»** отправляет две команды по очереди: сначала `/op <ваш сохранённый ник>`, затем `/pex user <выбранный ник>`. Сервер сам проверяет права и может отклонить команды; мод не выдаёт права в обход проверок сервера.
7. Чтобы изменить сохранённый ник или группу, нажмите **«Изменить»** в меню.

Мод работает на стороне клиента и отправляет команды подключённому серверу. Доступность и результат команд определяются настройками и правами на сервере.

## Для разработчиков

| Версия Minecraft | Исходники | Собранный JAR в репозитории |
| --- | --- | --- |
| 1.21.11 | `versions/1.21.11` | `artifacts/RuleHelper-1.21.11-Fabric.jar` |
| 1.21.4 | `versions/1.21.4` | `artifacts/RuleHelper-1.21.4-Fabric.jar` |

Обе версии собираются с JDK 21 через Gradle wrapper. GitHub Actions собирает обе версии после push или pull request и прикладывает JAR как workflow artifacts.

Исходники восстановлены из доступных JAR-файлов и адаптированы для указанных версий Minecraft, поэтому могут отличаться от исходного проекта автора.
