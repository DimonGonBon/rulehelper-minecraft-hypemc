# RuleHelper 2.0 — большое обновление донатерской версии

Новый редактор причин, проверка четырёх типов наказаний и единый интерфейс для трёх версий Minecraft — в одном релизе.

## Скачать свою версию

| Minecraft | Файл | Java | Fabric Loader |
| --- | --- | --- | --- |
| 26.3 | `RuleHelper-26.3-Fabric.jar` | 25 | 0.20.1+ |
| 1.21.11 | `RuleHelper-1.21.11-Fabric.jar` | 21 | 0.19.3+ |
| 1.21.4 | `RuleHelper-1.21.4-Fabric.jar` | 21 | 0.19.3+ |

Устанавливайте **только один JAR**, подходящий к вашей версии игры. Все три файла — донатерская версия RuleHelper 2.0.0. Fabric API и дополнительные моды для работы RuleHelper не требуются.

## Главное новое: свои причины для каждого правила

В меню **«Причина» → «Свой стиль»** появился полноценный редактор:

- **Общий шаблон** для правил без индивидуальных настроек.
- **Отдельное оформление каждого доступного донатерам пункта**: собственные цвета, символы и расположение текста.
- **Отдельный шаблон снятия** для разбана, размута и снятия предупреждения.
- Кнопки вставки цветов, жирного/курсива, подчёркивания и декоративных символов.
- **Живой предпросмотр** причины во время редактирования.
- Сохранение шаблонов между запусками. Переход между вкладками и правилами сохраняет черновики; применяются они по кнопке «Сохранить».
- Кнопка **«Как общий»** возвращает выбранному пункту общий шаблон. Готовые стили остаются доступны.

Подстановки:

| Подстановка | Значение |
| --- | --- |
| `{rule}` | Номер выбранного пункта |
| `{reason}` | Текст причины |
| `{extra}` | Уточнение варианта наказания, например «Родня» |

Уточнение варианта сохраняется и при отсутствии `{extra}` в шаблоне. Сам шаблон меняет причину; ник, срок и режим берутся из выбранного действия.

## Цветные причины и выбор стиля в окне проверки

Добавлен готовый **«Цветной курсив»**: пункт белый, текст наказания голубой, текст снятия зелёный. Причина остаётся одной строкой.

Пример наказания:
`&f&l&o2.3 &b&l&o━━➤ 「 Оскорбительное поведение 」&r`

Пример снятия:
`&f&l&o3.4 &a&l&o━━➤ 「 Некорректное наказание 」&r`

Кнопка **«Причина»** теперь есть и в окне **«Проверка наказания»**. Предпросмотр показывает цвет и начертание. Отображение этих кодов другим игрокам зависит от поддержки сервера и ваших прав.

## Баны, муты, предупреждения и кики

Окно проверки распознаёт все четыре типа объявлений:

- **Бан / мут:** снятие на режиме из исходного объявления и отдельное подтверждение выдачи 3.4 выдавшему игроку.
- **Предупреждение:** снятие через `/unwarn` на режиме из объявления, затем подтверждение 3.4. Если режим варна не указан, можно подготовить 3.4, а само предупреждение снять вручную.
- **Кик:** подготовка и подтверждение 3.4 без команды снятия — кик уже завершён.

Поддерживаются объявления «выдал предупреждение», «предупредил», «выдал варн», «кикнул», «выгнал» и «выкинул», в том числе предупреждения и кики без причины.

Синий щит **🛡** и красный череп **☠** в объявлениях копируют соответственно ник выдавшего и получившего наказание. Они работают и с варнами/киками. Предупреждения о возможном некорректном наказании также учитывают эти типы.

Режим снятия берётся из объявления: **Выживание, Гриферский, Мини-игры или глобальный**. Мод подставляет `server:…` либо соответствующий глобальный селектор. Текст уже отправленной команды снятия сохраняется в окне без последующего изменения.

## Единый интерфейс и остальные возможности

- Компактное синее меню: категории, поиск, список правил, описание, варианты наказаний и быстрые действия. Список при новом открытии начинается сверху.
- Префикс перед ником открывает меню игрока; при наведении виден выбранный ник. Сам ник копируется нажатием.
- Настраиваемые префиксы меню и уведомлений.
- Звуковые уведомления о возможных оскорблениях, упоминаниях родных и явно подозрительных наказаниях. Самостоятельно наказания не выдаются.
- Окно наказаний за календарный день: `/shist <ваш ник>`, разбор относительного времени каждой записи и отбор сегодняшних наказаний. Учитывается объём истории, возвращённый сервером. Ответ внутреннего запроса скрывается из чата; история другого игрока остаётся видимой.
- Сохранены доступные донатерам команды и настройка профиля «Правитель+» / «Staff–». Настройка не выдаёт серверные права.

Запрос доказательств, служебные экраны модераторов и очередь нарушителей в этот релиз не входят. Пункты, предназначенные только официальной команде, не добавлены в донатерское меню.

## Как установить и пользоваться

1. Удалите предыдущий JAR RuleHelper из папки `mods`.
2. Установите Fabric Loader для своей версии Minecraft и скачайте один подходящий файл из этого релиза.
3. Положите JAR в `mods` игрового профиля и запустите Fabric. Существующие настройки ника, доната и причин подхватываются из `config/rulehelper.properties`.
4. Откройте чат и нажмите префикс RuleHelper перед ником игрока. При первом запуске укажите свой серверный ник и настоящую группу доната.
5. Выберите пункт и действие. Для своего оформления откройте **«Причина» → «Свой стиль»**, настройте шаблон и нажмите **«Сохранить»**.
6. Для проверки наказания нажмите текст объявления в чате. Сверьте участников, причину, срок и режим, затем подтвердите действие.
7. **Home** открывает настройки. **F9** по умолчанию открывает дневную историю; эту клавишу можно переназначить в настройках.

**Правитель+** сохраняет глобальные команды для правил разделов 1–3; **Staff–** использует прежний локальный вариант. Правила разделов 4–5 и снятие по объявлению учитывают выбранный/определённый режим. Доступность команд проверяет сервер.

## Проверено

Все три сборки проходят компиляцию и автоматические проверки: геометрия кликов по чату, разбор объявлений и дневной истории, шаблоны/сохранение настроек, команды снятия, группы доната и отсутствие модераторских экранов в JAR. Полный запуск интерфейса и выполнение команд на HypeMC в рамках этой сборки не проверялись.
